# iVision Knowledge Hub guest demo

This static prototype uses fictional project emails generated for the Capstone. It demonstrates keyword search, topic and project filters, source viewing, and a timeline ordered by the synthetic emails’ sent times.

All data ships with the site. It does not connect to Azure, accept emails, publish Gold claims, deliver notifications, or execute rollbacks. Search runs in the browser without storing search history.

To preview locally, run `python -m http.server 8000` in this directory and open `http://127.0.0.1:8000/`.
